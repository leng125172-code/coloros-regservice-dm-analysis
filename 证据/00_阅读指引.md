# 投诉证据包 · 阅读指引

**投诉对象**：com.coloros.regservice（ColorOS / 一加 15 国行系统预装组件）
**核心问题**：无用户告知与开关的情况下，采集已安装应用清单、应用使用行为、设备与网络标识，并上传至第三方服务器
**证据提取方式**：本人在自有设备上以 adb + root **只读**提取，未修改任何系统文件

## 三条最关键的证据

1. **`02_证据_组件本体/采集数据库_脱敏版.db`** —— 打开可看到 524 条已安装应用记录（包名、启动次数、使用时长、每应用流量）、6010 条预装记录、173 条基站/卡号记录。行数与字段全部保留，仅标识值已脱敏。
2. **`03_证据_行为与配置/上传接口清单.md`** —— 5 个 HTTPS 接口的完整参数，包含 imei、imei2 等设备标识；接收方域名 fxltsbl.com 注册人为中国移动通信集团终端有限公司。
3. **`03_证据_行为与配置/采集开关配置.md`** —— 所有采集开关均为 Y，且由服务端下发覆盖，用户侧无关闭入口。

## 脱敏声明

原始数据中包含投诉人设备的 IMEI、ICCID、IMSI 与已安装应用清单。
为保护个人信息，提交版本已做如下处理：

| 数据 | 处理 |
|---|---|
| IMEI / ICCID / IMSI / CellID / LAC / PCI / BSSID / SSID / MAC | 统一替换为 `REDACTED` |
| 应用包名与应用名 | 统一替换为 `com.redacted.app` / `REDACTED_APP` |
| 表结构、行数、字段名、启动次数与流量数值 | **保留**（用于证明采集范围与粒度） |

原始未脱敏数据仅保留在投诉人本地设备，未随本包提交。
