来源：`/data/data/com.coloros.regservice/shared_prefs/config_dm.xml`
说明：这些开关**不在用户界面里**，由服务端 `TerminalConfigService/terminalConf` 下发覆盖。

## 四、采集频率（毫秒 / 小时）

| 参数 | 值 | 换算 |
|---|---|---|
| regRate | 86400000 | 每天注册一次 |
| keepAliveRate | 86400000 | 每天心跳一次 |
| networkInterval | 86400000 | 每天网络信息一次 |

| appDataLifeTime | 1296000000 | 应用数据保留 15 天 |
| flowDataLifeTime | 168 | 168 小时（7 天） |
| max_retry_count | 1 | 失败只重试 1 次 |

## 五、本地敏感值存放情况

`config_dm.xml` 里存在以下**明文/序列化**内容（已在本包中脱敏）：

- `KEY_INFORMATION_FOR_TRAFFIC`：Java 序列化对象，字段含 `cellId / cellId2 / lac / lac2 / pci1 / pci2 / iccid1 / iccid2 / imsi1 / imsi2 / channel1 / channel2`
- `KEY_IP_MAC_HASHMAP`：`<本机/路由器 MAC>` → `<出口 IP>` 的映射表
- `KEY_REGISITER_MD5`：注册标识的 MD5
- `key_max_report_current`：`4#<epoch_ms>`，表示当日已上报次数

**结论：IMEI/ICCID 这类标识在客户端是明文存放的，没有做本地加密。**
