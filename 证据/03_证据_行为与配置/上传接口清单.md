## 接口 1：取 IP（设备注册前置）

```
GET https://a.fxltsbl.com/getIpAddr
    ?appkey=A100000357
    &timestr=<epoch_ms>
    &imei=<REDACTED>
    &version=v2
    &token=<REDACTED>
```

响应头：`Server: nginx` / `Content-Type: application/octet-stream` / `Connection: Keep-alive`
说明：返回体 12~39 字节，应为设备出口 IP 或服务器地址。

## 接口 2：SDK 日志/数据上报（三个 func 共用一个路径）

```
POST https://a.fxltsbl.com/accept/sdkService?func=tsdk:postreglog
POST https://a.fxltsbl.com/accept/sdkService?func=tsdk:posthblog
POST https://a.fxltsbl.com/accept/sdkService?func=tsdk:postapplylog
```

共同参数：`appkey=A100000357&timestr=<epoch_ms>&imei=<REDACTED>&version=v2&token=<REDACTED>`
`Content-Type: application/json`

| func | 含义（按命名推断） | 抓到的频次 |
|---|---|---|
| postreglog | 设备注册上报 | 每日 |
| posthblog | 心跳上报 | 每日 1 次（23:xx） |
| postapplylog | 应用数据上报 | 采集周期结束后 |

## 接口 3：终端配置下发（服务端控制开关）

```
GET https://a.fxltsbl.com/TerminalConfigService/terminalConf
    ?func=tsdk:termimalfullconfig
    &brand=OnePlus
    &model=PLK110
    &mac=
    &imei=<REDACTED>
    &imei2=<REDACTED>
    &version=v2
    &sdkver=5.0.4_Android
    &dynamicVer=0
    &action=filter
    &timestr=<epoch_ms>
    &token=<REDACTED>
    &appkey=A100000357
```

响应头出现 `Alt-Svc: h3=":443"; ma=86400`（支持 HTTP/3）
说明：**这是"云控"的关键**——客户端所有的上报开关都由这个接口下发的 JSON 决定。
