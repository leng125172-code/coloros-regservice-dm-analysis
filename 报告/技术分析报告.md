采集方式：adb + root 只读提取（未修改任何系统文件）

## 一、结论先行

**这不是木马，是运营商入库合规的 DM 云控 SDK。** 但它的采集面确实超出了一般"设备注册"所需。

| 判断项 | 结论 |
|---|---|
| 归属 | 域名 `fxltsbl.com` 注册人为**中国移动通信集团终端有限公司**（京ICP备17049465号-4） |
| 载体 | 系统预装包 `com.coloros.regservice`（`/product/app/RegService.apk`），内部命名空间 `com.dmyk.android.telephony` |
| SDK | 彩讯（richinfo）DM 云控 SDK，`appkey=A100000357`，`sdkver=5.0.4_Android` |
| 传输 | 全程 HTTPS（未发现明文 HTTP 上报），服务端 nginx，支持 HTTP/3 |
| 证书 | DigiCert **DV** 通配符证书 `*.fxltsbl.com`（仅验证域名所有权，不含组织信息） |
| 组件暴露 | `exported=true` 组件数 **0**，外部应用无法调用 |
| 静默录屏/截屏 | **无**（另案：小布识屏有截屏能力，但需用户手势触发） |

## 二、它采集了什么（实证）

数据库 `/data/data/com.coloros.regservice/databases/cmcc_dm.db`（851KB）：

| 表 | 行数 | 内容 |
|---|---|---|
| `app_info_<周期>` | **524** | 每个已安装应用的包名、名称、启动次数、使用时长、移动/WiFi 收发流量、安装时间、UID |
| `table_name_preinstall` | **6010** | 预装应用包名、版本、签名信息、安装时间 |
| `table_app_collect_list` | 1 | 采集周期起止 + ICCID1/2 + IMSI1/2 |
| `table_of_time_related_traffic` | 173 | 按天记录 IMSI/ICCID/LAC/CellID/PCI |
| `table_name_network` / `net_speed` | 7 / 7 | BSSID、SSID、IMSI、小区、信号强度、路由器 IP |
| `table_name_wifi_list` | 2 | WiFi 列表 |
| `table_name_battery_charge` | 2 | 电量、温度 |

配合 `config_dm.xml` 里的 `KEY_INFORMATION_FOR_TRAFFIC`（Java 序列化）与 `KEY_IP_MAC_HASHMAP`，
可以还原出：**设备装了什么、用多久、耗多少流量、在哪个基站/WiFi 下、换了哪张卡**。

## 三、值得警惕的四点

1. **无任何用户可见入口**
   桌面无图标，设置里无开关，用户既不知道它在跑，也不知道它在采什么。

2. **开关控制权在服务端**
   所有"上报/采集"开关由 `TerminalConfigService/terminalConf` 下发。用户即使改本地配置，下次拉取又会被覆盖。

3. **采集面超出"设备注册"所需**
   正常的设备注册只需要 IMEI/型号/系统版本。这里还包含：应用清单（524 条）、使用时长、每应用流量、WiFi 列表与 BSSID、蓝牙开关、漫游状态、充电状态、基站三元组。

4. **敏感标识本地明文存放**
   IMEI1/IMEI2/ICCID1/ICCID2/IMSI1/IMSI2 在 `shared_prefs` 中是明文/可逆序列化，未做本地加密。

## 四、不构成"木马"的证据

- 包在系统分区 `/product/app/`，签名与系统一致（平台签名）
- 没有任何 `exported=true` 组件，外部无法调用
- 上报走 HTTPS，且服务端证书链正常（DigiCert → `*.fxltsbl.com`）
- 域名注册主体明确可查（中国移动终端公司）
- 没有发现静默录屏、键盘记录、通话录音等行为

## 六、如何自行复核

```bash
# 1. 确认域名归属（ICP 备案）
#    京ICP备17049465号-4 → 中国移动通信集团终端有限公司

# 2. 看证书是不是 DV（无组织信息）
openssl s_client -connect a.fxltsbl.com:443 -servername a.fxltsbl.com </dev/null 2>/dev/null \
  | openssl x509 -noout -subject -issuer

# 3. 看本机接口缓存
adb shell su -c 'ls /data/data/com.coloros.regservice/cache/volley/ | wc -l'
adb shell su -c 'strings /data/data/com.coloros.regservice/cache/volley/* | grep fxltsbl | head'

# 4. 看数据库
adb shell su -c 'cp /data/data/com.coloros.regservice/databases/cmcc_dm.db /sdcard/'
adb pull /sdcard/cmcc_dm.db .
sqlite3 cmcc_dm.db '.tables'
```

## 七、处置建议（任选）

```bash
# A. 彻底断（推荐）：禁用整包 + 清已采集数据
adb shell pm disable-user --user 0 com.coloros.regservice
adb shell su -c 'rm -f /data/data/com.coloros.regservice/databases/cmcc_dm.db*'
adb shell su -c 'rm -rf /data/data/com.coloros.regservice/cache/volley/*'

# B. 轻量：只断域名（保留功能，数据不出门）
#    用 Magisk hosts 模块把 a/b.fxltsbl.com 指向 0.0.0.0

# C. 保留但减采集：撤销定位类 appops
adb shell cmd appops set com.coloros.regservice FINE_LOCATION ignore
adb shell cmd appops set com.coloros.regservice COARSE_LOCATION ignore
```

注意：`TeleService` 引用了 `dmyk`，禁用后极少数运营商的 APN 自动配置可能不触发；可随时 `pm enable` 回滚。

## 八、上传给监管部门的版本说明

`cmcc_dm_sanitized.db` 是**脱敏版**数据库，用于随投诉提交：

- 保留全部 12 张表结构与行数（524 / 6010 / 173 / 7 …），足以证明采集范围与粒度；
- 所有 IMSI/ICCID/CellID/LAC/PCI/BSSID/SSID/MAC 字段统一替换为 `REDACTED`；
- 应用清单中的包名替换为 `com.redacted.app`、应用名替换为 `REDACTED_APP`，仅保留数量与字段结构。

原始 `cmcc_dm.db`（含完整设备标识）**仅保留在本人设备与本地，不随投诉上传**。
