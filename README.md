# ColorOS 预装组件 `com.coloros.regservice` 数据采集行为分析

> 一台一加 15（国行 PLK110，ColorOS 16.0.10.502 / Android 16）的实测记录。
> 全部数据由设备所有者在自有设备上以 **adb + root 只读方式**提取，未修改任何系统文件。
> 最新采集：2026-11-27 15:10（首次采集 10:53）

---

## 摘要

ColorOS 国行固件预装的 `com.coloros.regservice`（内部命名空间 `com.dmyk.android.telephony`，集成彩讯 richinfo DM 云控 SDK）在**无桌面入口、无系统设置开关、无独立隐私告知**的情况下，持续采集已安装应用清单、应用使用行为与流量、设备与网络标识，并通过 HTTPS 上报至 `fxltsbl.com`（域名注册人：中国移动通信集团终端有限公司，京ICP备17049465号-4）。

实测显示该组件**连续 26 天每日自动上报**，且所有采集开关由服务端下发覆盖，用户侧无关闭入口。

## 二、实测采集范围

| 数据类别 | 表名 | 行数 | 字段 |
|---|---|---|---|
| 已安装应用 | `app_info_*` | **524** | 包名、应用名、启动次数、使用时长、移动/WiFi 收发流量、安装时间、UID |
| 预装应用 | `table_name_preinstall` | **6010** | 包名、版本、签名信息、安装时间 |
| 卡与基站 | `table_of_time_related_traffic` | 172 | 按天记录 ICCID1/2、IMSI1/2、LAC、CellID、PCI |
| 网络环境 | `table_name_network` / `net_speed` | 7 / 7 | BSSID、SSID、路由器出口 IP、信号强度 |

| 电量 | `table_name_battery_charge` | 3 | 电量、电池温度、充电状态 |
| 蓝牙 | `table_name_bluetooth` | 0 | 蓝牙名称/MAC/UUID（表已建，待采集） |

## 三、实测上报行为

| 接口 | 方法 | 缓存中请求数 | 连续天数 |
|---|---|---|---|
| `/getIpAddr` | GET | 21 | 21 天 |
| `/accept/sdkService?func=tsdk:postreglog` | POST | 1 | 注册一次 |
| `/accept/sdkService?func=tsdk:posthblog` | POST | 25 | 25 天（心跳） |
| `/accept/sdkService?func=tsdk:postapplylog` | POST | 3 | 采集周期结束 |
| `/TerminalConfigService/terminalConf` | GET | 25 | 25 天（下发开关） |

```
时间跨度：2026-11-02 07:27:53 → 2026-11-27 14:44:20
```

请求参数中携带 `imei`、`imei2`；服务器证书为 DigiCert 签发的 `*.fxltsbl.com`（DV 级，仅域名验证）。

## 六、隐私与脱敏

| 数据 | 处理 |
|---|---|
| IMEI / ICCID / IMSI / CellID / LAC / PCI / BSSID / SSID / MAC | 统一替换为 `REDACTED` |
